# Random Quote Generator

**Автор:** Ахмадуллин Данил

## Описание
GUI-приложение на Python (библиотека `tkinter`), предназначенное для генерации случайных цитат. Приложение позволяет выбирать цитаты на основе фильтров (по автору и по теме), сохраняет историю всех сгенерированных цитат в JSON-файл, а также дает возможность пользователю добавлять свои собственные цитаты с проверкой на пустые строки.

## Технические особенности (.grid)
В данном приложении для размещения элементов интерфейса используется метод `.grid()`.
* **Сетка:** Позволяет располагать виджеты в ячейках таблицы (строки и столбцы).
* **Параметры:**
    * `row` и `column`: определяют позицию элемента.
    * `sticky="w"`: прижимает текст к западному (левому) краю ячейки.
    * `padx` и `pady`: добавляют внешние отступы, чтобы интерфейс не выглядел "слипшимся".

## Примеры использования / Тесты

1. **Генерация без фильтров:** - Выберите "Все" в фильтрах автора и темы.
   - Нажмите "Сгенерировать цитату". Появится случайная цитата, которая также добавится в историю.
2. **Фильтрация:** - Выберите конкретного автора. Приложение будет выдавать цитаты только этого автора.
3. **Добавление новой цитаты:** - Введите текст, автора и тему. 
   - Нажмите "Добавить". Новые данные сохранятся в `quotes.json`.
4. **Проверка ввода (Тест):** - Попробуйте добавить цитату с пустым полем. Программа выдаст предупреждение.
